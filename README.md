Prune-cleaner 🧹

一个功能残缺、令人火大的电脑垃圾清理工具。
别人有的它有，别人没有的它没有，毫无竞争力。

🤔 这是什么？

这是一个用 Python 编写的简易电脑清理工具。虽然它自称“功能残缺”，但它依然能帮你清理掉一些系统里不必要的垃圾文件。

⚠️ 警告：
本工具目前处于“实验性”阶段。虽然开发者（我）已经尽力测试，但清理类软件总是伴随风险。
请在运行前确认你了解它在做什么，重要数据请务必备份！

✨ 功能特点

极简主义：没有复杂的设置，主打一个“随缘清理”。
python驱动：核心逻辑基于Python 脚本 (`main.py`)。
安装包支持：提供Windows安装包，无需配置 Python 环境即可运行。
开源免费：代码完全公开，欢迎大佬们来“喷”或者修补我的代码。

 🚀 如何获取？

你可以直接下载编译好的安装包：

1. 前往右侧栏的Releases区域。
2. 下载最新版本的.exe安装包。
3. 运行安装程序，按照提示完成安装。
